# 診断結果の送り方

結果を送る方法は3つあります。**上の2つは設定なしで今すぐ使えます。**

| 方法 | 設定 | 送れるもの | 使う場面 |
| --- | --- | --- | --- |
| メールで送る | 不要 | 本文（テキスト） | その場ですぐ共有したいとき |
| LINEなどで送る | 不要 | 本文（テキスト） | スマホから店長へ送るとき |
| PDFを自動送信 | 必要（このページ） | PDF＋本文 | 記録として残したいとき |

いずれも、開始時に**受診者が共有に同意している場合のみ**表示されます。

## 設定なしで送る（今すぐ使えます）

結果画面の下、「結果を送る」の中にあります。

- **メールで送る** — スマホのメールアプリが開きます。宛先（本部と、入力されていればご本人）・件名・本文がすべて入った状態なので、送信ボタンを押すだけです。
- **LINEなどで送る** — 端末の共有メニューが開きます。LINEを選べば、店長やご本人にそのまま送れます。（共有メニューに対応していない端末では、代わりに本文をコピーします）

どちらも**本文のみでPDFは付きません**。PDFが必要なら「保存・印刷」で保存してから添付してください。

# PDFの自動送信をセットアップする

ここから先は、結果を**PDFにして自動でメール送信**したい場合の設定です。

Google Apps Script を使うので、**新しいサービスへの登録や費用は不要**です。すでにお持ちの `trainers.gym00@gmail.com` の中だけで完結します。

所要時間は10分ほど。**パソコンでの作業をおすすめします**（スクリプトの貼り付けとデプロイ設定があるため、スマホだけだとかなり操作しづらいです）。

---

## 1. スクリプトを作る

1. `trainers.gym00@gmail.com` でログインした状態で https://script.google.com を開く
2. 左上の「**新しいプロジェクト**」をクリック
3. 最初から入っている `function myFunction() {}` を全部消す
4. このリポジトリの `tools/gas-enneagram-mailer.gs` の中身を**全部コピーして貼り付ける**
5. 左上のプロジェクト名を「エニアグラム診断メール送信」などに変更して保存（⌘S / Ctrl+S）

## 2. 送信先を設定する

貼り付けたコードの上のほうにある設定を直します。

```javascript
var HQ_EMAIL = 'trainers.gym00@gmail.com';   // 本部。ここは必ず届く
```

店長にも届けたい場合は、`MANAGERS` の右側にアドレスを書きます。**空のままなら本部にだけ届きます。**

```javascript
var MANAGERS = {
  '駒沢大学店': 'komazawa@example.com',   // ← 記入すると店長にも届く
  '高円寺店':   '',                        // ← 空なら本部のみ
  ...
};
```

結果PDFを Google ドライブにも残したい場合は、保存先フォルダのIDを入れます（フォルダを開いたときのURLの `folders/` 以降の文字列）。空なら保存しません。

```javascript
var ARCHIVE_FOLDER_ID = '';
```

## 3. 公開する

1. 右上の「**デプロイ**」→「**新しいデプロイ**」
2. 左の歯車マーク → 種類として「**ウェブアプリ**」を選ぶ
3. 次のように設定する
   - 説明：任意（「エニアグラム診断」など）
   - 次のユーザーとして実行：**自分（trainers.gym00@gmail.com）**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押す
5. 初回は権限の確認が出ます。「アクセスを承認」→ アカウントを選ぶ →「詳細」→「（プロジェクト名）に移動」→「許可」

> 「このアプリは確認されていません」という警告が出ますが、ご自身で作ったスクリプトなので問題ありません。

6. 表示された **ウェブアプリURL**（`https://script.google.com/macros/s/……/exec`）をコピーする

### 動作確認

コピーしたURLをブラウザのアドレスバーに貼って開いてください。次のように表示されれば成功です。

```json
{"ok":true,"message":"エニアグラム診断の送信先として稼働しています"}
```

## 4. 診断アプリにURLを設定する

`enneagram.html` を開き、`SEND_ENDPOINT` にコピーしたURLを貼ります。

```javascript
/* 変更前 */
var SEND_ENDPOINT="";

/* 変更後 */
var SEND_ENDPOINT="https://script.google.com/macros/s/AKfycb…/exec";
```

これで、結果画面に「**PDFを送信する**」ボタンが出るようになります。

## 送信されるもの

| 宛先 | 届くもの |
| --- | --- |
| 本部（`HQ_EMAIL`） | 結果PDF＋本文にタイプ・スコア一覧・受診者情報 |
| 店舗担当者（`MANAGERS` に記入がある場合のみ） | 本部と同じもの |
| 受診者本人（メールアドレスを入力した場合のみ） | 結果PDF＋タイプの案内文 |

## 送信されない場合

受診者が**共有に同意していない**ときは、どの方法でも送信できません。**診断そのものは受けられます。**

その場合は、結果画面の「保存・印刷」からPDFを保存して手渡ししてください。

`SEND_ENDPOINT` が空のままでも、上に書いた「メールで送る」「LINEなどで送る」は使えます。

## うまくいかないとき

- **送信できませんでした、と出る** — ウェブアプリURLが正しいか、手順3の「アクセスできるユーザー：全員」になっているかを確認してください。設定を直したら、必ず「デプロイ」→「デプロイを管理」から**新しいバージョンとして再デプロイ**してください（コードを直しただけでは反映されません）。
- **本部に届かない** — 迷惑メールフォルダを確認してください。
- **エラーの中身を見たい** — 送信に失敗すると、本部宛に「【要確認】エニアグラム診断の送信に失敗しました」という件名でエラー内容が届きます。

## 個人情報の取り扱いについて

- 氏名・メールアドレス・診断結果を本部と店舗で共有します。開始画面の同意チェックがオンのときだけ送信されます。
- 送信しない限り、回答内容は受診者の端末内（ブラウザ）にのみ残ります。
- 診断結果は評価や選別のためのものではない旨を、受診者に伝えたうえで実施してください。
