## 2. 28日スプリント計画(9/7〜10/4)

### 逆算ファネル(目標: 外部8名 ※9/7確定 — 「残り3名」は訴求上の表示であり実残席は8)

```
LP流入 1,500〜2,000(広告+オーガニック+直接開拓)
 → 説明会予約 45〜60(CVR 3%)
 → 説明会実施 32〜42(no-show 3割見込み・前日リマインドで圧縮)
 → 申込 8〜10(成約率 25%)
```
広告10万円で見込める流入は700〜1,200クリック(CPC 80〜150円想定)= **必要流入の半分**。
残り半分は無料導線で作る。特に**治療院・接骨院への直接開拓**は「流入→説明会」を飛ばして
「紹介→説明会予約」に直結するため、ファネル効率が広告の数倍。W1からこちらを主軸に置く。

※LPの残席表示について: 実残席(8)と異なる「残り3名」表示は有利誤認(景品表示法)のリスクがあるため
LPには載せず、「定員8名・先着順」+「申込締切9/28」+締切カウントダウンで緊急性を作る方式に変更済み。
申込が実際に入り次第、「残り◯名」の実数表示に切り替える(これが最も強い訴求になる)。
