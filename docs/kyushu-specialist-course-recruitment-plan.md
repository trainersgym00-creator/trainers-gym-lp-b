# 開講(2026年10月)までに16名を集める募集戦略プラン

作成日: 2026-08-01
目標: **2026年9月末までに入学生16名確定**
- 内部枠: 九州医療スポーツ専門学校 在学生 8名
- 外部枠: 一般(社会人・他校生・転職希望者など) 8名

残り期間: **約9週間(8月第1週〜9月末)**

---

## 1. 基本方針

内部8名と外部8名は「獲得の難易度」も「打ち手」も全く別物なので、**2本の独立したファネルとして並行運用**する。

| | 内部枠(在学生8名) | 外部枠(一般8名) |
|---|---|---|
| リーチ手段 | 学校経由(既にリストがある) | 広告・SNS・紹介で新規獲得 |
| 難易度 | 低〜中(接触は容易、決断が焦点) | 高(認知ゼロから9週間) |
| 主戦場 | 校内説明会・個別面談 | LP+Meta/Instagram広告+体験会 |
| 勝負どころ | 8月中に説明会→9月上旬までに面談完了 | 8月中旬までに広告開始(遅れが致命傷) |

**最重要の考え方: 逆算ファネル。** 「16名」から逆算して、何人と面談し、何人を説明会に呼び、何人にリーチする必要があるかを先に決め、週次で進捗管理する。

## 2. 逆算ファネル設計(仮定値ベース)

※ 転換率は業界一般値からの仮定。初週の実測値で必ず更新すること。

### 内部枠(在学生 8名)

```
在学生全体へ告知(全学科)
  → 説明会/体験授業 参加: 30名(仮定: 対象学年の2〜3割)
  → 個別面談: 16名(参加者の5割)
  → 入学申込: 8名(面談の5割)
```

### 外部枠(一般 8名)

```
LP流入: 3,000〜4,000セッション(広告中心)
  → LINE登録/資料請求 CV: 90〜120件(CVR 3%)
  → 説明会・体験会 参加: 35〜45名(登録の4割)
  → 個別面談: 20名
  → 入学申込: 8名(面談の4割)
```

外部は「LP→即申込」ではなく **「LINE登録→体験会→個別面談→申込」** の多段ファネルにする。高額・進路系の意思決定は一発CVしないため。

## 3. 内部枠(在学生8名)の具体策

学校側と共同で動けるのが最大の武器。**8月中に3回接触**が目標ライン。

### 3-1. 施策リスト

1. **校内説明会 + 体験授業(8月中に2回、9月上旬に1回)**
   - トレーナーズラボ現役講師によるデモセッション(実技を見せる)が最も刺さる
   - 夏休み期間の登校日・オープンキャンパス日に合わせて開催
2. **学校公式チャネルでの告知**
   - 担任・キャリア担当からの声かけ(教員推薦は在学生に最も効く)
   - 学内掲示・学校公式LINE/Instagramでの配信
3. **在学生限定の早期特典**
   - 「9月15日までの申込で入学金減免」等の締切付きオファー(要学校・ラボ間で条件決定)
4. **キャリア接続の明示**
   - 「修了後、TRAINER'S GYM(東京7店舗)への就職ルートあり」は専門学校生への最強の訴求。求人条件を明文化して説明会で提示
5. **個別面談の即時セット**
   - 説明会当日にその場で面談予約を取る(後日連絡は歩留まりが半減する)

### 3-2. 内部枠スケジュール

| 週 | アクション |
|---|---|
| 8月 W1 | 学校側と告知計画合意・説明会日程確定・告知物制作 |
| 8月 W2 | 校内告知開始(掲示・LINE・教員声かけ) |
| 8月 W3 | 第1回 校内説明会+体験授業 → 当日面談予約 |
| 8月 W4〜9月 W1 | 個別面談ラッシュ / 第2回説明会 |
| 9月 W2 | 早期特典締切 → 申込確定処理 |
| 9月 W3〜W4 | 未達なら個別追客・最終説明会で残席クローズ |

## 4. 外部枠(一般8名)の具体策

ゼロから8名は9週間ではタイト。**8月中旬までに広告を回し始められるかが全て。**

### 4-1. 専用LP(最優先・今週着手)

- 本リポジトリの制作アセット(TRAINER'S GYM LPのデザインシステム)を流用して**コース専用LP**を最速で構築
- 構成案:
  1. ヒーロー: 「2026年10月開講・限定16名」+ 締切カウントダウン
  2. こんな人へ: 未経験からトレーナーへ / 医療×スポーツの専門性 / 転職
  3. コース内容・カリキュラム・講師
  4. 卒業後のキャリア(TRAINER'S GYM就職ルート・提携先)
  5. 料金・入学までの流れ
  6. CTA: **LINE登録 or 体験会予約**(電話・フォームより心理障壁が低い)
- 残席表示(「外部枠 残り○名」)で希少性を可視化

### 4-2. 有料広告(8月W2開始)

- **Meta広告(Instagram/Facebook)を主軸**: 福岡県+近隣県、20〜35歳、フィットネス・転職関心層
- 予算目安: 月30〜50万円 × 2ヶ月(CPA 3〜6万円/LINE登録ベースで90〜120件を狙う水準)
- クリエイティブは「ビフォーアフター」ではなく**「トレーナーになる」キャリア訴求**(体験授業動画・講師の実演・修了生の就職先)
- 補助: Google検索広告(「パーソナルトレーナー スクール 福岡」「トレーナー 資格 専門学校」等の指名・顕在ワード。ボリュームは小さいがCVRが高い)

### 4-3. 無料集客・信頼形成(並行)

1. **体験会イベント(8月下旬・9月中旬の2回、学校校舎で開催)** — 外部者が校舎・設備を見る機会そのものが説得材料
2. **プレスリリース**(PR TIMES等): 「東京のトレーナー養成スクールが九州初進出」は地方紙・業界メディアが拾いやすいニュース
3. **Instagram/TikTokオーガニック**: 開講までの舞台裏・講師紹介・体験会の様子を週3投稿
4. **紹介インセンティブ**: トレーナーズラボ卒業生・TRAINER'S GYM会員・提携ジム経由の紹介に特典
5. **地域提携**: 福岡近郊のフィットネスジム・整骨院にチラシ設置/スタッフ向け案内(働きながら学びたい層に直接届く)

### 4-4. 追客(ナーチャリング)

- LINE登録者へステップ配信(コース紹介→講師紹介→卒業後キャリア→体験会案内→締切告知)
- 体験会参加者は**48時間以内に個別面談の打診**(鉄は熱いうちに)
- 9月中旬以降は「残席○名・締切○日」の締切訴求に全面切り替え

## 6. KPI管理(週次レビュー必須)

毎週月曜に以下を確認し、仮定値と実測値の乖離があれば即打ち手を変える。

| 指標 | 内部枠目標 | 外部枠目標 |
|---|---|---|
| 説明会/体験会 参加累計 | 30名 | 40名 |
| 個別面談 実施累計 | 16名 | 20名 |
| **申込確定** | **8名** | **8名** |
| LP CVR(外部) | - | 3%以上 |
| CPA(LINE登録) | - | 5,000円以下目安 |

**危険シグナルと対処:**
- 8月末時点で内部面談が8件未満 → 教員経由の個別声かけを追加、特典増額を検討
- 8月末時点で外部LINE登録が40件未満 → 広告予算増額 or ターゲット/クリエイティブ変更
- 9月中旬で合計10名未満 → 内部・外部の枠の垣根を外し、取れる方から埋める判断も
